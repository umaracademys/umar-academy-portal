# 🎫 Teacher Ticket Workflow - Complete User Guide

## 📋 Overview

Teachers can now create tickets independently, review them, and assign homework after admin approval. This guide explains how to use the new workflow.

---

## 👨‍🏫 **FOR TEACHERS**

### **Step 1: Create a Ticket**

1. **Login** to your Teacher Dashboard
2. **Click "Create Ticket"** button in the Quick Actions section (green button with 🎫 icon)
3. **Select Student** from your assigned students dropdown
4. **Choose Ticket Type:**
   - **Sabq** 📖 - New material review
   - **Sabqi** 📚 - Review of previously learned material  
   - **Manzil** 📿 - Large portion review (multiple Juz)
5. **Fill in Details:**
   - For **Sabq**: Enter comment/notes
   - For **Sabqi/Manzil**: Enter your notes (teacher selection is auto-filled)
6. **Click "Create Ticket"**

✅ **Ticket Created!** Status: `pending` → You'll see it in "Pending Tickets"

---

### **Step 2: Review Ticket & Mark Mistakes**

1. **Go to "Pending Tickets"** section on your dashboard
2. **Click "Start Review"** on a ticket
3. **Interactive Mushaf Opens:**
   - Navigate to the relevant page
   - Click on words/letters to mark mistakes
   - Select mistake type (memory, tajweed, etc.)
   - Add notes if needed
   - Add audio recording (optional)
4. **Add Comment:**
   - Write your review notes
   - Describe student's performance
5. **Click "Submit for Review"**

✅ **Ticket Submitted!** Status: `submitted` → Waiting for admin approval

---

### **Step 3: Assign Homework (After Approval)**

1. **Wait for Admin Approval**
   - Admin reviews your ticket
   - Admin clicks "Approve & Send"
   - Ticket status changes to `sent_to_assignment`

2. **See Approved Ticket:**
   - Go to **"Approved Tickets - Assign Homework"** section
   - You'll see tickets that need homework assignment

3. **Click "Assign Homework"** button

4. **Smart Suggestions Appear:**
   - System analyzes mistakes from your ticket
   - Suggests homework ranges based on mistakes
   - **Sabq**: Suggests Surah-Ayah ranges
   - **Sabqi**: Suggests Juz ranges
   - **Manzil**: Suggests multiple Juz

5. **Use Suggestions:**
   - **Use**: Instantly adds suggestion as homework
   - **Modify**: Pre-fills form, you can edit before adding
   - **Ignore**: Create homework manually

6. **Add Homework Items:**
   - Select homework type
   - Fill in range details:
     - **Sabq**: Select Surah, enter From/To Ayah
     - **Sabqi**: Choose Surah→Surah or Juz→Juz mode
     - **Manzil**: Select multiple Juz checkboxes
   - Click "Add Item" to add to list
   - Add multiple items if needed

7. **Add Notes** (optional):
   - General instructions for student

8. **Click "Save Homework"**

✅ **Homework Assigned!** Student will see it on their dashboard

---

## 👨‍💼 **FOR ADMINS/SUPER ADMINS**

### **Step 1: Review Submitted Tickets**

1. **Login** to Admin/Super Admin Dashboard
2. **Go to "Manage Tickets"** or check notifications
3. **Find tickets with status: `submitted`**
4. **Click on ticket to review:**
   - View teacher's comment
   - See mistakes marked in Mushaf
   - Review audio recordings (if any)

### **Step 2: Approve Ticket**

1. **Review the ticket thoroughly**
2. **Click "Approve & Send to Assignment"**
3. **System automatically:**
   - Creates/updates assignment for student
   - Adds classwork entry (sabq/sabqi/manzil)
   - Transfers mistakes to assignment
   - Syncs mistakes to Student Personal Mushaf
   - Updates ticket status to `sent_to_assignment`

✅ **Ticket Approved!** Teacher can now assign homework

## ❓ **Common Questions**

### **Q: Can I create tickets for students not assigned to me?**
**A:** No. You can only create tickets for your assigned students. The system validates this automatically.

### **Q: What if I make a mistake in a ticket?**
**A:** You can update tickets that are still `pending` or `in_progress`. Once submitted, admin must approve changes.

### **Q: Can I assign homework before admin approval?**
**A:** No. Homework can only be assigned after admin approves the ticket and it becomes `sent_to_assignment`.

### **Q: What if admin rejects my ticket?**
**A:** Admin can request changes. You'll see the ticket status and can update it accordingly.

### **Q: How do smart suggestions work?**
**A:** System analyzes mistakes you marked:
- Groups mistakes by surah/ayah
- Suggests ranges covering those mistakes
- Helps assign relevant practice

### **Q: Can I assign multiple homework items?**
**A:** Yes! You can add multiple homework items of different types (Sabq, Sabqi, Manzil).

## 📞 **Need Help?**

If you encounter any issues:

1. **Check Permissions:**
   - Ensure `canCreateTickets` is enabled
   - Verify students are assigned to you

2. **Check Ticket Status:**
   - `pending` - Waiting for you to review
   - `in_progress` - You're working on it
   - `submitted` - Waiting for admin
   - `sent_to_assignment` - Ready for homework

3. **Contact Admin:**
   - If tickets aren't showing
   - If you can't create tickets
   - If homework assignment fails
